# **App Name**: Studygram Students Community

## Core Features:

- Login Identification: A simple login page requiring only email and student name for identification and database storage. This eliminates the need for a full account creation process.
- Chat History Storage: All chat messages are stored and available for all students to view, even if they were not active during the initial conversation. Implemented with a system that automatically purges chat history older than 15 days, ensuring data privacy and storage efficiency.
- File Uploads: Users can upload various file types including images, videos, and documents directly within the chat interface to share with others.

## Style Guidelines:

- Background color: Deep, rich blue (#3366CC) for a luxurious feel.
- Card Background: Slightly darker blue (#3366B3) for the main chat container to create depth.
- Primary/Accent Color: Vibrant gold (#D1A041) used for borders, headers, and interactive elements to provide a premium look.
- Body Text/Foreground: Soft, off-white (#D3D6DC) for readability against the dark background, ensuring the text is easily legible.
- Main headlines: 'Literata' (serif) for headlines and main text, providing an elegant and classic touch.
- Body text and chat messages: 'Inter' (sans-serif) for all body text and chat messages to maintain a clean and highly readable appearance.
- Central, card-like container with large rounded corners and a distinct gold border to make it stand out against the dark background.
- Separator lines for the header and footer will be stylish horizontal gradients that fade from transparent to the gold accent color in the middle.
